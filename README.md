# miguelvielma.com

Sitio personal de Miguel Vielma: servicios de automatización para pymes (bots de WhatsApp,
automatizaciones y páginas que venden) y portafolio.

## Cómo está hecho

- HTML, CSS y JavaScript sin dependencias ni proceso de compilación.
- Tipografías autoalojadas (Archivo y JetBrains Mono, licencia SIL OFL).
- Sin cookies, analítica ni recursos de terceros.
- Política de seguridad de contenido estricta: solo se cargan recursos del propio sitio.
- Publicado con GitHub Pages en el dominio definido en `CNAME`.

## Verlo en local

```
python tools/servidor.py 8083
```

y abrir `http://127.0.0.1:8083/` en el navegador. El servidor solo escucha en este equipo.

## Estructura

```
index.html                 portada, servicios, demo del bot y contacto
automatizaciones.html      detalle de servicios y preguntas frecuentes
proyectos.html             proyectos verificables
privacidad.html            política de privacidad (Ley 19.628 y 21.719)
cookies.html               política de cookies
terminos.html              términos y condiciones de uso
condiciones-servicio.html  condiciones de contratación y encargo de tratamiento
eliminar-datos.html        instrucciones para eliminar datos
assets/                    estilos, scripts, tipografías e imágenes
tools/servidor.py          servidor local sin caché para desarrollo
```
